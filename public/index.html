BRING YOUR LENS ALONG

Connect your extension

  1. Open chrome://extensions in Chrome.
  2. Enable Developer mode, choose Load unpacked, and select this project's extension folder.
  3. Pin Feed Lens. Paste the code below into its popup.
  4. Open LinkedIn Home. Set your topic and what makes a post useful, then choose Start my lens.

The code changes when you restart this server. Keep the server running. The browser extension uses live Jev. Add your own key to .env.local before starting it. You can also test it on this fictional sample feed.

After you start the lens, posts are scored as they enter view. Background tabs do not start new requests. Choose Pause to stop and remove badges.
